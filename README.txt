MANIMOZHI | PREMIUM BIRTHDAY SURPRISE

1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Safari, or Firefox.
3. Click "Unwrap your surprise" to start.

Includes all HTML5, CSS3, JavaScript and the original photograph (manimozhi.jpg).
The user-supplied hosted image address is retained in the page as shared-source metadata.
The photo is displayed using a local bundled copy so the website still works without internet access.
Google Fonts enhance the appearance when online; fallback fonts are available offline.

To host as a shareable public URL, upload these files together to Netlify Drop, GitHub Pages, or another static hosting provider.
